MCLink 是 Windows 11 x64 原生桌面应用，让文本模型通过 Minecraft Java 协议作为独立玩家执行任务、聊天和查看地图。

### 下载与启动

下载 `MCLink-0.5.0-win-x64.zip`，完整解压后运行 `MCLink/MCLink.App.exe`。包内已包含 .NET、Windows App SDK、Node.js 和桥接依赖，无需另行安装这些运行时。`MCLink-0.5.0-win-x64.sha256` 提供下载校验。

首次启动需自行配置模型 API 和 Minecraft 连接；发行包不含 API 密钥或账号缓存。原生界面支持 Windows 11 x64，游戏连接支持 Minecraft Java 版。

### 本版改进

- 模型默认一次规划最多 4 个动作，减少每个动作后的推理停顿；查询、受伤、动作失败和环境变化后重新观察与规划。
- 临时 API 或网络错误保留当前目标并自动恢复；重试不消耗游戏动作步数，保留停止、健康和错误次数限制。
- 任务、聊天、API 测试和模型列表共用请求队列。默认最短请求间隔 8 秒，可配置；429 使用指数退避并遵守服务端 Retry-After。
- 合并短时间内连续到来的玩家消息，减少重复聊天请求；移除模型历史中的重复背包快照。
- 新增每批动作数和 API 请求间隔设置，支持加密保存与重启恢复。

包含可选 Java 1.21.11 Fabric 客户端转发模组 0.4.0 和对应 Fabric API，安装说明位于 `MCLink/client-mod/README.md`。使用原版 `/msg 机器人名 /指令` 时无需安装该模组。
